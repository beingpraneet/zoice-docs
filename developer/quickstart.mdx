## Welcome to Zoice Developer Platform

Zoice Dev provides high-performance, developer-friendly APIs to generate realistic AI avatar videos, human-grade text-to-speech audio, custom image generations, and voice profiles. Integrate all these capabilities under one unified developer account.

---

## 1. Get your API Key

To get started, you will need a Zoice developer account and an API Key:

1. Visit the [Zoice Dev Console](https://dev.zoice.com/).
2. Log in or create a new account by clicking **Get Started**.
3. Locate your API Key on the developer dashboard. Keep this key secure, and do not share it publicly.

---

## 2. Authenticate Your Requests

All requests to Zoice APIs require authorization. Add the following header to your API requests:

```http
Authorization: Bearer <YOUR_ZOICE_API_KEY>
```

---

## 3. Generate Your First AI Avatar Video

Create a talking avatar video by sending a `POST` request to the `zoice/avatar-x` endpoint. 

Below are code examples in various languages showing how to initiate a video generation:

<CodeGroup>

```bash cURL
curl -X POST "https://dev.zoice.com/v1/run/zoice/avatar-x" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ZOICE_API_KEY" \
  -d '{
    "avatar_id": "ad4ed5d7-22eb-4939-8ee2-a16fbd9dcf1b",
    "voice_id": "a737e319-8b5b-43e8-a189-c45fcd9def3a",
    "script_text": "Hi! This is my first digital twin talking using the Zoice Avatar X API."
  }'
```

```javascript Node.js
fetch("https://dev.zoice.com/v1/run/zoice/avatar-x", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": `Bearer ${process.env.ZOICE_API_KEY}`
  },
  body: JSON.stringify({
    avatar_id: "ad4ed5d7-22eb-4939-8ee2-a16fbd9dcf1b",
    voice_id: "a737e319-8b5b-43e8-a189-c45fcd9def3a",
    script_text: "Hi! This is my first digital twin talking using the Zoice Avatar X API."
  })
})
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));
```

```python Python
import os
import requests

api_key = os.getenv("ZOICE_API_KEY")
url = "https://dev.zoice.com/v1/run/zoice/avatar-x"

headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {api_key}"
}

payload = {
    "avatar_id": "ad4ed5d7-22eb-4939-8ee2-a16fbd9dcf1b",
    "voice_id": "a737e319-8b5b-43e8-a189-c45fcd9def3a",
    "script_text": "Hi! This is my first digital twin talking using the Zoice Avatar X API."
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

</CodeGroup>

### Request Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `avatar_id` | `string` | **Yes** | The unique identifier of the avatar presenter character to use. |
| `voice_id` | `string` | **Yes** | The unique identifier of the voice profile to speak the script. |
| `script_text` | `string` | **Yes** | The text content to speak. Recommended maximum of 1,000 characters. |

### Response Example

A successful request returns a JSON object containing the status and the generated video URL:


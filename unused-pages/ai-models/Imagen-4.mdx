## Overview

Imagen 4 is the flagship image generation model available on Zoice, representing the cutting edge of AI image synthesis. It offers unparalleled quality, stunning photorealism, and sophisticated understanding of complex prompts.

Use Imagen 4 when you need the absolute best image quality and the most accurate interpretation of detailed prompts.

## Model Parameters

The Imagen 4 model supports the following parameters:

| Parameter | Type | Required | Description |
|--------|------|----------|-------------|
| `prompt` | string | Yes | Text description of the image you want to generate |
| `resolution` | string | No | Output image size (default: `1024x1024`) |
| `aspect_ratio` | string | No | Image aspect ratio (e.g., `16:9`, `1:1`, `4:3`) |
| `count` | number | No | Number of images to generate (1-4) |
| `seed` | number | No | Seed value for reproducible outputs |
| `style` | string | No | Style preset (e.g., `photographic`, `artistic`, `cinematic`) |

## Overview

Image Reference to Video allows you to create videos that match the style, composition, or subject of a reference image. Upload an image and describe the motion or action you want, and the AI will generate a video that maintains visual consistency with your reference.

## How It Works

The AI analyzes your reference image to understand composition, style, colors, and subject matter, then generates a video that incorporates these elements while adding the motion and action described in your prompt.

## Image Requirements

### Technical Specifications
- **Formats**: JPG, PNG, WebP
- **Max Size**: 10MB
- **Recommended Resolution**: 1024x1024 or higher
- **Aspect Ratio**: Match your desired video aspect ratio

### Content Guidelines
- Clear, well-composed images work best
- Good lighting and focus
- Relevant to the video you want to create
- High quality produces better results

## Reference Influence Strength

Control how much the video follows the reference image:

<Tabs>
  <Tab title="Low (0.2-0.4)">
    **Loose Inspiration**
    - General style guidance
    - Color palette reference
    - Mood and atmosphere
    - More creative freedom
    
    **Best For:**
    - Style inspiration
    - Color scheme reference
    - General aesthetic guidance
  </Tab>
  
  <Tab title="Medium (0.5-0.7)">
    **Balanced Guidance**
    - Maintains composition
    - Follows style closely
    - Preserves key elements
    - Balanced creativity
    
    **Best For:**
    - Character consistency
    - Scene recreation
    - Product videos
  </Tab>
  
  <Tab title="High (0.8-1.0)">
    **Strong Adherence**
    - Very close to reference
    - Minimal deviation
    - Strict composition
    - Limited creative variation
    
    **Best For:**
    - Animating static images
    - Precise style matching
    - Brand consistency
  </Tab>
</Tabs>

## Writing Effective Prompts

### Prompt Structure

When using reference images, your prompt should focus on:

1. **Motion/Action**: What should move and how
2. **Camera Work**: How the camera should move
3. **Preservation**: What to keep from the reference
4. **Additions**: New elements to add

### Example Prompts

<CodeGroup>
```text Subtle Animation
Gentle camera push in, subject's clothing moving slightly 
in wind, hair flowing softly, maintain exact composition 
and lighting from reference image
```

```text Dynamic Action
Camera orbiting around subject, dramatic movement, 
cinematic style, maintain color palette and mood from 
reference, add motion blur for speed
```

```text Environmental Motion
Static camera, clouds moving across sky, water rippling, 
trees swaying, keep exact composition and framing from 
reference image, natural movement
```
</CodeGroup>

## Advanced Techniques

### Layered Motion
Describe different motion for different elements:

```text
Foreground: person walking slowly from left to right
Midground: cars passing by with motion blur
Background: clouds drifting, maintain reference composition
Camera: slight pan following main subject
```

### Temporal Consistency
For character or product consistency across multiple videos:

1. Use same reference image
2. Keep similar strength settings
3. Maintain consistent prompt structure
4. Use same model for all generations

### Hybrid Approach
Combine reference image with detailed text descriptions:

```text
Using reference image for character appearance and style,
add dynamic action: character jumping and spinning,
camera slow motion, dramatic lighting, cinematic style,
maintain character design from reference
```

## Comparison: Text-Only vs Image Reference

| Aspect | Text-to-Video | Image Ref to Video |
|--------|---------------|-------------------|
| **Control** | Description-based | Visual-guided |
| **Consistency** | Variable | More predictable |
| **Creativity** | High freedom | Guided creativity |
| **Use Case** | New concepts | Style matching |
| **Setup** | Faster | Requires image |

## Troubleshooting

<AccordionGroup>
  <Accordion title="Video doesn't match reference">
    - Increase reference strength
    - Simplify motion prompt
    - Use higher quality reference image
    - Mention "maintain reference style" in prompt
  </Accordion>
  
  <Accordion title="Too similar to static image">
    - Decrease reference strength
    - Add more dynamic motion descriptions
    - Increase motion intensity setting
    - Use more active verbs in prompt
  </Accordion>
  
  <Accordion title="Inconsistent style">
    - Increase reference strength
    - Use clearer reference image
    - Simplify the prompt
    - Try different model
  </Accordion>
</AccordionGroup>

<Tip>
For best results, use reference images that clearly show the style, composition, or subject you want in your video.

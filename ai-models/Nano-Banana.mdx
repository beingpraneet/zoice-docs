## Overview

Nano Banana is a lightweight image generation model available on Zoice. It is designed for speed and efficiency, making it ideal for rapid image creation where low latency matters more than ultra-high detail.

Use Nano Banana when you need quick previews, concept visuals, or bulk image generation without heavy compute requirements.

---

## Key Capabilities

- Fast image generation with minimal processing time
- Optimized for short and simple prompts
- Low credit consumption compared to advanced models
- Suitable for previews, drafts, and experimentation

---

## Best Use Cases

Use Nano Banana for the following scenarios:

- Rapid prototyping and concept testing
- Generating multiple image variations quickly
- Background visuals or placeholder assets
- Budget-friendly image generation workflows

---

## Model Parameters

The Nano Banana model supports the following parameters:

| Parameter | Type | Required | Description |
|--------|------|----------|-------------|
| `prompt` | string | Yes | Text description of the image you want to generate |
| `resolution` | string | No | Output image size (default: `1024x1024`) |
| `count` | number | No | Number of images to generate |
| `seed` | number | No | Seed value for reproducible outputs |

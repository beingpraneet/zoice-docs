## Overview

Veo 3.1 is the latest generation video model available on Zoice. It represents a significant advancement in AI video generation, offering superior quality, better motion coherence, and enhanced visual fidelity.

Use Veo 3.1 when you need premium video content with the highest level of detail and realism.

## Model Parameters

The Veo 3.1 model supports the following parameters:

| Parameter | Type | Required | Description |
|--------|------|----------|-------------|
| `prompt` | string | Yes | Text description of the video you want to generate |
| `duration` | number | No | Video length in seconds (default: `5`) |
| `resolution` | string | No | Output video resolution (default: `1080p`) |
| `fps` | number | No | Frames per second (default: `24`) |
| `seed` | number | No | Seed value for reproducible outputs |

## Overview

Veo 3.1 supports reference images for precise style and content control, perfect for branded content and consistent visual styles.

## Quick Start

<Steps>
  <Step title="Select Veo 3.1">
    Choose from model selector
  </Step>
  <Step title="Upload Reference">
    Select reference image
  </Step>
  <Step title="Write Prompt">
    Describe motion and changes
  </Step>
  <Step title="Generate">
    Create your video
  </Step>
</Steps>

## Best Practices

- Use high-quality references
- Describe desired motion
- Specify camera work
- Set appropriate strength

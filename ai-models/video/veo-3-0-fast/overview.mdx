## Generation Modes

Veo 3.0 Fast currently supports:

- **Image to Video** - Transform static images into dynamic video content
- **Frame to Video** - Create smooth animations from multiple frames

<Note>
  Text to Video mode is not available in Veo 3.0 Fast. For text-based generation, consider using Veo 3.1 or Veo 3.1 Fast.
</Note>

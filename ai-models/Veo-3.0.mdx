## Overview

Veo 3.0 is a proven video generation model on Zoice, offering excellent quality and consistent results. It provides a great balance between quality, speed, and cost-effectiveness.

Use Veo 3.0 when you need reliable, high-quality video generation for professional projects.

---

- Excellent video generation quality
- Reliable and consistent outputs
- Strong motion coherence
- Good understanding of detailed prompts
- Balanced performance and quality

---

## Model Parameters

The Veo 3.0 model supports the following parameters:

| Parameter | Type | Required | Description |
|--------|------|----------|-------------|
| `prompt` | string | Yes | Text description of the video you want to generate |
| `duration` | number | No | Video length in seconds (default: `5`) |
| `resolution` | string | No | Output video resolution (default: `1080p`) |
| `fps` | number | No | Frames per second (default: `24`) |
| `seed` | number | No | Seed value for reproducible outputs |

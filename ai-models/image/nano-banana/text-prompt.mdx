## Overview

Learn how to generate high-quality images quickly using Nano Banana's text-to-image capabilities. This guide covers prompt writing, parameters, and best practices specific to the Nano Banana model.

## Quick Start

<Steps>
  <Step title="Select Nano Banana Model">
    Choose "Nano Banana" from the model selector
  </Step>
  <Step title="Write Your Prompt">
    Enter a detailed description of your desired image
  </Step>
  <Step title="Set Parameters">
    Configure resolution, aspect ratio, and other settings
  </Step>
  <Step title="Generate">
    Click generate and wait 3-5 seconds
  </Step>
  <Step title="Refine">
    Adjust prompt and regenerate if needed
  </Step>
</Steps>

## Prompt Writing for Nano Banana

### Optimal Prompt Structure

Nano Banana works best with clear, structured prompts:

```text
[Subject] + [Style] + [Details] + [Quality Keywords]
```

### Example Prompts

<CodeGroup>
```text Photography
A professional product photo of a smartwatch on a marble surface, 
soft studio lighting, clean composition, sharp focus, high quality, 
detailed, 4K
```

```text Illustration
A cute cartoon cat sitting on a windowsill, pastel colors, 
soft shading, children's book illustration style, whimsical, 
charming, detailed
```

```text Landscape

dramatic clouds, vibrant colors, nature photography, 
high detail, beautiful composition
```

```text Abstract
Abstract geometric shapes in blue and gold, modern art style, 
clean lines, minimalist, professional, high contrast, 
digital art, crisp
```
</CodeGroup>

## Model-Specific Tips

### Leverage Speed
- Generate multiple variations quickly
- Test different prompt variations
- Iterate rapidly to find best results
- Use for A/B testing concepts

### Optimize for Web
- 1024x1024 is the sweet spot
- Perfect for social media
- Fast loading times
- Good quality-to-size ratio

### Keep Prompts Focused
- Nano Banana excels with clear, focused prompts
- Avoid overly complex scenes
- Stick to 2-3 main elements
- Be specific about style

## Parameters

### Resolution Options
- **512x512**: Ultra-fast, testing
- **1024x1024**: Standard, recommended
- **1536x1536**: High quality
- **2048x2048**: Maximum quality

### Aspect Ratios
- **1:1 (Square)**: Social media, profile images
- **16:9 (Landscape)**: Web headers, YouTube thumbnails
- **9:16 (Portrait)**: Instagram Stories, mobile
- **4:3 (Standard)**: Presentations, general use

### Advanced Settings
- **Guidance Scale**: 7-12 (recommended: 9)
- **Steps**: 20-30 (recommended: 25)
- **Seed**: Random or fixed for consistency

## Common Use Cases

### Social Media Graphics
```text

and blue gradient background, clean typography space, 
professional, trendy, high quality

Settings:
- Resolution: 1024x1024
- Aspect Ratio: 1:1
- Guidance: 9
```

```text
- Aspect Ratio: 16:9
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Image lacks detail">
    - Add "detailed" and "high quality" to prompt
    - Increase resolution
    - Raise guidance scale slightly
    - Be more specific in description
  </Accordion>
  
  <Accordion title="Wrong style">
    - Make style keywords more prominent
    - Put style at beginning of prompt
    - Use specific style references
    - Try different style keywords
  </Accordion>
  
  <Accordion title="Unexpected elements">
    - Simplify prompt
    - Remove ambiguous descriptions
    - Be more explicit
    - Lower guidance scale
  </Accordion>
</AccordionGroup>

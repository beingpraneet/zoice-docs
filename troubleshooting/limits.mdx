## Overview

Zoice implements usage limits to ensure fair access and optimal performance for all users. This guide explains the limits, how they work, and how to work within them effectively.

## Credit Limits

### Account Credit Limits
- **Free Trial**: 50 credits (one-time)
- **Pay-As-You-Go**: No limit (purchase as needed)
- **Starter Plan**: 500 credits/month + rollover
- **Professional Plan**: 2,000 credits/month + rollover
- **Business Plan**: 7,500 credits/month + rollover
- **Enterprise**: Custom limits

### Credit Rollover
- **Subscription Plans**: Unused credits roll over to next month
- **Maximum Rollover**: Up to 2x monthly allocation
- **Example**: Starter plan can accumulate up to 1,000 credits
- **Purchased Credits**: Never expire, no rollover limit

## What Happens When You Hit a Limit?

### Rate Limit Exceeded
**Response:**
- Generation request queued or rejected
- Error message displayed
- Retry-after time provided

**Solutions:**
- Wait for limit reset (hourly/daily)
- Upgrade to higher plan
- Spread generations over time
- Use API with backoff strategy

### Credit Limit Exceeded
**Response:**
- Generation blocked
- Purchase prompt displayed
- Current work saved

**Solutions:**
- Purchase additional credits
- Upgrade subscription plan
- Wait for monthly renewal (subscriptions)

### Storage Limit Exceeded
**Response:**
- Cannot save new generations
- Warning message displayed
- Oldest files marked for deletion

**Solutions:**
- Download and delete old files
- Upgrade storage plan
- Enable auto-cleanup
- Archive important files locally
